Почему указатель, а не просто int?
Потому что функция возвращает целый массив (копию), а не одно число. В массив нельзя вернуть «как есть» — он возращает указатель на первый элемент массива.



for (int i = 0; i < size - 1; i += 1) 
        for (int j = 0; j < size - 1; i += 1) 

почему i < size and (-1) ???

после каждого прохода один самый большой элемент встаёт в конец на своё место.

Аналогия: 4 человека по росту. 
Ставишь самого высокого в конец → готов 1. 
Среди оставшихся 3 — ещё один → готовы 2. 
Среди оставшихся 2 — ещё один → готовы 3. 
Последний сам окажется на месте. 
Итого 3 действия для 4 человек = size - 1.
